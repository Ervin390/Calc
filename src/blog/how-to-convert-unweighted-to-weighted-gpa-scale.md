# How to Convert Unweighted to Weighted GPA Scale

Converting an unweighted Grade Point Average (on a 4.0 max scale) to a weighted scale (typically 5.0) rewards students for taking challenging course loads such as Advanced Placement (AP), International Baccalaureate (IB), and Honors classes.

Because an unweighted GPA treats an $A$ in standard physical education the same as an $A$ in AP Calculus, high schools use weighted scales to reflect academic rigor. This guide explains how to convert unweighted grades into a weighted GPA using our [<a href="/gpa-calculator/">GPA Calculator</a>](/gpa-calculator/).

---

## Standard Course Weighting Scale

On a weighted scale, extra points (called "weights") are added to letter grades earned in advanced classes:

| Letter Grade | Regular Course (4.0) | Honors Course (+0.5) | AP / IB Course (+1.0) |
| :--- | :--- | :--- | :--- |
| **A** | 4.0 | 4.5 | **5.0** |
| **B** | 3.0 | 3.5 | **4.0** |
| **C** | 2.0 | 2.5 | **3.0** |
| **D** | 1.0 | 1.5 | **2.0** |
| **F** | 0.0 | 0.0 | **0.0** |

---

## Step-by-Step Weighted GPA Calculation

To convert your transcript to a weighted GPA:

1. **Assign weighted point values** to each grade based on course difficulty level.
2. **Multiply each course's point value by its credit hours** to calculate total quality points.
3. **Sum total quality points and divide by total attempted credits.**

$$\text{Weighted GPA} = \frac{\sum (\text{Course Grade Points} + \text{Weight}) \times \text{Credits}}{\text{Total Attempted Credits}}$$

### Worked Example:

A student takes 4 courses (3 credits each):
- AP English: Grade **A** (5.0 weighted points x 3 credits = 15.0)
- Honors Chemistry: Grade **B** (3.5 weighted points x 3 credits = 10.5)
- Standard History: Grade **A** (4.0 unweighted points x 3 credits = 12.0)
- AP Calculus: Grade **B** (4.0 weighted points x 3 credits = 12.0)

$$\text{Total Quality Points} = 15.0 + 10.5 + 12.0 + 12.0 = 49.5$$
$$\text{Total Credits} = 12$$
$$\text{Weighted GPA} = \frac{49.5}{12} = \mathbf{4.125}$$
